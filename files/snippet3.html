The "Logical Value" Rule

A memory location might physically contain a Descriptor, but logically it represents a value. If the status is Succeeded, the logical value is new_value; otherwise, it's old_value.

helping_protocol.ml
OCaml 5.0 Atomics
(* Resolving what a cell logically holds *) let logical_value wd = if Atomic.get wd.parent.status = Succeeded then wd.new_value (* MCAS committed *) else wd.old_value (* MCAS failed/pending *) let rec read_internal addr = match Atomic.get addr with | Value v -> v | Word wd -> (* Foreign MCAS found, must help *) if Atomic.get wd.parent.status = Active then (help wd.parent; read_internal addr) else logical_value wd
Progress Guarantee

System-wide progress is guaranteed because threads cooperate rather than block.

Linearizability

The read operation appears atomic because it resolves the descriptor state immediately.

Recursion Safety

Helping is recursive but finite, bounded by the number of active operations.

Phase 1: Word Acquisition & Locking

The Harris-Fraser-Pratt "Helping" Protocol

Linearization Point
Status CAS(Active → Succeeded)
Memory Cell Transition

The cell now points to a Word Descriptor, signaling other threads to "help" or wait.

1

Cooperative Sorting

To prevent deadlocks, all target words are sorted by their memory addresses. Threads acquire cells in a deterministic global order.

2

Discovery & Helping

If acquire_word finds another descriptor, it recursively calls help. This ensures the system is lock-free: at least one operation in the system is always making progress.

core_mcas.ml (Acquire Loop)
while !success && !i < Array.length desc.words do if not (acquire_word desc desc.words.(!i)) then success := false; Stdlib.incr i done;

Crucial Edge Case

If acquisition fails at any word, the operation transitions to FAILED. All acquired words are then rolled back to their old values.

Decision Point

Once all words are acquired, a Single CAS on the descriptor status field commits the entire transaction.
